# Database Management Systems

Notes and reference material for DBMS. The written guides are browser-ready HTML
files, so they keep their formatting when opened directly.

## Available material

- **DBMS Exam Guide** — question patterns, model answers and the topics that
  repeat every year.
- **DBMS Schema Protocol** — how to lay out an answer-sheet schema: keys,
  relationships, constraints and the order to draw them in.

Both are in `resources/` and appear in the download table below.

## What the paper covers

| Unit | Topics |
|---|---|
| 1 | Introduction, database users, DBMS architecture, data independence |
| 2 | ER model, entities, relationships, cardinality, generalisation |
| 3 | Relational model, keys, relational algebra, SQL |
| 4 | Normalisation — 1NF to BCNF, functional dependencies, decomposition |
| 5 | Transactions, concurrency control, recovery, indexing |

## Adding to this page

PDFs, slides or diagrams anywhere in this folder (except `notes/`) and they show
up in the download list.
