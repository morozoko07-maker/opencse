# Data Structures and Applications

A complete, page-by-page study guide written from the module PDFs, split into
readable chapters. Each chapter uses the same rhythm:

- **Plain-English idea** — what the thing actually is.
- **Exam definition** — the sentence you can reproduce in the answer sheet.
- **Worked trace** — how the algorithm moves, step by step.
- **Exam points** — the small facts that become 1–2 mark questions.
- **Check yourself** — questions with answers, right after the topic.
- **Question bank** — exam-style questions at the end.

## How to revise with these

1. Read a section once without trying to memorise it.
2. Close it and explain the idea out loud in your own words.
3. Answer the "check yourself" questions.
4. Only then look at the code and the trace.
5. Finish with the question bank, closed book.

Code for the practicals lives in `notes/` alongside the theory so the trace and
the program can be read together.
