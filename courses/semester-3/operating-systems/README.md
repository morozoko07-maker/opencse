## How the paper is usually split

- **CIE (50)** — internal tests / IA, quizzes, assignments and lab work.
- **SEE (50)** — one written paper covering all modules.

## Suggested order of study

1. Processes and threads — states, PCB, context switch.
2. CPU scheduling — FCFS, SJF, SRTF, priority, round robin; practise Gantt charts.
3. Synchronisation — critical section, semaphores, classic problems.
4. Deadlock — conditions, prevention, avoidance (Banker's), detection.
5. Memory — paging, segmentation, page replacement, thrashing.
6. File systems and disk scheduling.
